# Learning notes

Write a short note after each step: five minutes, while it is fresh. At the end of a
milestone, turn the notes into a write-up (`milestone-1.md`, `milestone-2.md`, and so on).
Later they become your README, blog posts or portfolio.

Template:

```markdown
## 2026-11-12: Ray Tracing in One Weekend, chapters 1 to 6

- Built:
- Learned:
- Surprised me:
- Stuck on, and how I got unstuck:
- Next:
```
